## 6 个可直接抄的模板

### 模板 1 · 显示文字

static void ui_main(void)

### 模板 2 · 显示会变的数字

```c
static void ui_main(void)
{
    char buf[24], *p = buf;
    int  v = (int)(HAL_GetTick() / 100);      /* 换成你的数据 */

    p = ui_str(p, "value = ");
    p = ui_itoa(p, v);

    ui_field(0, 20, 60, 200, 18, buf, C_WHITE, C_BG);
}
```

### 模板 3 · 显示带小数的电压

```c
static void ui_main(void)
{
    uint16_t code = 2048;                          /* ADC 12位 0..4095 */
    int32_t  mv   = (int32_t)code * 3300 / 4095;   /* 转毫伏，整数运算 */

    char buf[20], *p = buf;
    p = ui_fix(p, mv, 3);                          /* -> "1.650" */
    p = ui_str(p, " V");

    ui_field(0, 20, 60, 160, 18, buf, C_AMBER, C_BG);
}
```

/* ---- ui_main() 里 ---- */
if (ui_button(&s_btn, 20, 100, 150, 42, "PRESS ME", 0))

### 模板 6 · 物理按键

```c
/* main.c 的 USER CODE BEGIN WHILE 里 */
key_mod = get_keynum();                    /* 1=长按 2=双击 3=单击 */

if (key_mod == 1)                          /* 长按 */
{
    /* 做点事 */
    key_mod = 0;
}
if (key_mod == 2 || key_mod == 3)          /* 单击 / 双击 */
{
    /* 做点事 */
    key_mod = 0;
}
```

### 模板 6.5 · 触摸按键 vs 物理按键（★ 别搞混）

板子上有**两种按键**，写的地方完全不同：

| | 触摸按键（屏幕上） | 物理按键（PG7） |
|---|---|---|
| 写在哪个文件 | **`ui_demo.c` 的 `ui_main()`** | **`main.c` 主循环** |
| 怎么读 | `ui_button(&b, ...)` 返回 1 | `get_keynum()` 返回 1/2/3 |
| 长按 / 双击 | ❌ 不支持 | ✅ `1`=长按 `2`=双击 `3`=单击 |
| 谁画 | `ui_button()` 自己画 | 你自己在 `ui_main()` 里画 |

**`ui_main()` 里不要调 `get_keynum()`** —— 它是消费型的，读一次就清零，别的文件就读不到了；
而且 `ui_main()` 的职责只是"画"。

```c
/* main.c 主循环：读物理按键 */
key_mod = get_keynum();
if (key_mod != 0)
{
    if (key_mod == 3)  g_page = (g_page + 1) % 3;   /* 切页 */
    if (key_mod == 1)  g_run  = !g_run;             /* 暂停/运行 */
    key_mod = 0;
}
```

```c
/* ui_demo.c 的 ui_main()：只按状态画，同时创建触摸按键 */
static void ui_main(void)
{
    static ui_btn_t b = UI_BTN_DEFAULT;             /* 必须 static */

    if (ui_button(&b, 20, 40, 110, 36, "NEXT", 0))
        g_page = (g_page + 1) % 3;                  /* 点中 = 切页 */

    /* 再按 g_page 画页面内容 */
}
```

> 一句话：**物理按键在 `main.c` 里读，触摸按键在 `ui_main()` 里创建**，
> 两者都通过全局变量（如 `g_page`）影响界面。

详细说明见 `触摸屏使用说明.md` 第 0.7 / 0.8 节。

## 刷新是自动的（25fps）

`main.c` 主循环每 40ms 调一次 `ui_draw()`，它内部会调你的 `ui_main()`。

| 事情 | 自动吗 |
|---|---|
| 调 `ui_main()` | ✅ 25fps |
| 清屏 | ❌ 不会（框架不清屏）|
| 记住你画的东西 | ❌ 每帧重新执行你的代码 |
| 跳过没变的像素 | ✅ `ui_field` / `ui_button` 内部有缓存 |

**推荐写法**：静态内容每帧重画一遍（写的是同样像素，看不出来），会变的部分用 `ui_field`。

**想改速度**：`main.c` 里 `HAL_GetTick() - last_ui >= 40`，改成 `20` 就是 50fps。

> ⚠ 别在 `ui_main()` 里用 `HAL_Delay()`，会把整帧拖慢。

## 出错速查

| 现象 | 原因 |
|---|---|
| 编译报 `xxx undeclared` | 忘了 `#include "ui_render.h"` 或 `"touch.h"` |
| 全黑屏 | `ui_main()` 是空的 —— 正常。先贴第 3 步那 8 行验证 |
| 屏幕亮着但没内容 | 代码写在 `main()` 里了，要写在 `ui_main()` 里 |
| 触摸没反应 | `main.c` 里 `ui_touch_set(...)` 那段被删了 |
| 按键一闪一闪 | `ui_btn_t` 少了 `static` |
| 数字显示乱码 | `ui_fix(p,165,2)` 才出 `1.65`，传 `1.65` 是错的 |
| 中文显示成空白 | 字库只有 ASCII `0x20~0x7E` |
| 界面很卡 | 每帧整屏 `ui_fill` 了；改用 `ui_field` 或只画变化的部分 |
| `printf` 没输出 | 看错地方了，要用 `Debug (printf) Viewer`；SWO 时钟设 1MHz |
