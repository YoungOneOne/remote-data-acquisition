# 触摸屏使用说明（FT5336 / STM32F746G-DISCO）

> 相关文件：`Core/Inc/touch.h`、`Core/Src/touch.c`（驱动）、
> `Core/Inc/ui_render.h`、`Core/Src/ui_render.c`（显示 + 按键 + 准星）
> 屏幕：480 × 272，RGB565

---

## 0. 快速上手（先看这一章，5 分钟能用）

> 只想马上跑起来就看这章；原理和细节在后面第 1~8 章。

### 0.1 读触摸坐标 / 是否按下

```c
#include "touch.h"

Touch_State ts;

Touch_Init();                     /* 开机调一次 */

/* 主循环里 */
Touch_Poll(&ts);

ts.pressed      /* 1 = 按下，0 = 松开  ← 判断是否按下的唯一依据 */
ts.x            /* 0 ~ 479 */
ts.y            /* 0 ~ 271 */
ts.count        /* 触摸点数，单指 = 1 */
```

前后沿（可选）：

```c
uint8_t ev = Touch_Poll(&ts);

if (ev & TOUCH_EV_DOWN) { /* 刚按下 */ }
if (ev & TOUCH_EV_UP)   { /* 刚抬起 */ }
```

### 0.2 生成一个按键

```c
#include "ui_render.h"

static ui_btn_t b = UI_BTN_DEFAULT;        /* ① 定义，必须用这个宏初始化 */

static void my_ui(void)                    /* ② 每帧调一次 */
{
    if (ui_button(&b, 20, 40, 100, 36, "START", 0))
    {
        /* ③ 点中了，这里干活 */
    }
}

ui_set_custom(my_ui);                      /* ④ 开机注册一次 */
```

**`ui_button()` 参数**

```c
int ui_button(ui_btn_t *b, int x, int y, int w, int h, const char *label, int on);
```

| 参数 | 说明 |
|---|---|
| `&b` | 按钮对象 |
| `20, 40` | 左上角 x, y |
| `100, 36` | 宽, 高 |
| `"START"` | 按钮文字（ASCII），传 `0` = 不写字 |
| `0` | `1` = 显示成"选中/高亮"，`0` = 普通 |

**返回值**

- `1` = **这次点中了**（按下瞬间触发一次，按住不连发）
- `0` = 没点中 / 没变化 → **什么都不用做**

### 0.3 按键的初始化（★ 这一节最容易踩坑）

#### ① 两种写法，二选一

```c
/* 方式一：声明时用宏（最简单，推荐）*/
static ui_btn_t b = UI_BTN_DEFAULT;

/* 方式二：运行时调函数（数组批量初始化、复位时用）*/
static ui_btn_t btn[3];
int i;
for (i = 0; i < 3; i++)
    ui_btn_init(&btn[i]);
```

两种效果完全一样。`UI_BTN_DEFAULT` 就是把下面这些初值填好：

| 成员 | 宏给的初值 | 谁维护 |
|---|---|---|
| `x, y, w, h` | 0 | 每次 `ui_button()` 重新写入 |
| `label` | 0 | 同上 |
| `fg` / `bg` | `C_TB_TX` / `C_TB_BTN` | 松开时的文字色 / 底色 |
| `fg_on` / `bg_on` | `C_GREEN` / `C_TB_BTN_ON` | 按下或选中时的文字色 / 底色 |
| `on` | 0 | `ui_button()` 的 `on` 参数 |
| `down` / `drawn` / `last_vis` | 0 | `ui_button()` 内部缓存，**别手动改** |

#### ② ★★ 必须是 static 或全局，不能是普通局部变量

```c
void my_ui(void)
{
    ui_btn_t b = UI_BTN_DEFAULT;      /* ✗ 错！每帧都是全新的对象 */
    ui_button(&b, 20, 40, 100, 36, "BTN", 0);
}
```

`ui_button()` 要在**帧与帧之间**记住三件事：

- `drawn` —— 这个按钮画过没有（没画过才重画）
- `last_vis` —— 上次画成什么样子（状态没变就不重画，所以不闪）
- `down` —— 手指现在是不是按在它上面

普通局部变量每帧重建，这三样全丢 → **按钮每帧重画一次（会闪）、按住状态也错乱**。

正确写法（三选一）：

```c
/* ① 文件内静态 —— 最常用 */
static ui_btn_t b = UI_BTN_DEFAULT;

/* ② 函数内静态 —— 只在这个函数里用 */
void my_ui(void)
{
    static ui_btn_t b = UI_BTN_DEFAULT;
    ...
}

/* ③ 全局 —— 要跨文件访问时（头文件里 extern ui_btn_t b;）*/
ui_btn_t b = UI_BTN_DEFAULT;
```

#### ③ 不要写成 `= {0}`

```c
static ui_btn_t b = {0};      /* ✗ 配色全 0 = 全黑，按钮看不见 */
```

#### ④ 多个按钮用数组

```c
#define NB  3

static ui_btn_t btn[NB] = { UI_BTN_DEFAULT, UI_BTN_DEFAULT, UI_BTN_DEFAULT };
static const char *lab[NB] = { "CH1", "CH2", "D1" };
static int  sel;

void my_ui(void)
{
    int i;

    for (i = 0; i < NB; i++)
    {
        if (ui_button(&btn[i], 10 + i * 110, 40, 100, 36, lab[i], sel == i))
            sel = i;
    }
}
```

#### ⑤ 改配色

```c
static ui_btn_t b = UI_BTN_DEFAULT;

void ui_init_btns(void)                 /* 开机调一次 */
{
    ui_btn_colors(&b, C_WHITE, C_TB_BTN, C_BLACK, C_AMBER);
    /*              文字色   底色      选中文字色  选中底色 */
}
```

#### ⑥ 没有"创建 / 删除"，也不需要注册

`ui_btn_t` 就是个普通结构体，**没有动态内存**，所以：

- 没有 `ui_btn_create()` / `ui_btn_destroy()`
- 不需要把按钮"注册"到某个列表
- 第一次调 `ui_button()` 时它自己就画出来了（因为 `drawn == 0`）

#### ⑦ 复位 / 强制重画

```c
ui_btn_invalidate(&b);      /* 只让下一帧重画，状态保留（区域被别人盖住时用）*/
ui_btn_init(&b);            /* 连状态和配色一起恢复成默认值 */
```

### 0.4 两种常见按键

**普通按钮**（点一下计数 / 执行一次）

```c
static int cnt;

if (ui_button(&b, 20, 40, 100, 36, "BTN", 0))
    cnt++;
```

**开关按钮**（按一下切换状态，保持高亮）

```c
static int on;

if (ui_button(&b, 20, 40, 100, 36, "ON/OFF", on))
{
    on = !on;
    ui_btn_invalidate(&b);      /* 让按钮按新状态重画 */
}
```

**改配色**

```c
ui_btn_colors(&b, C_WHITE, C_TB_BTN, C_GREEN, C_TB_BTN_ON);
/*              文字色   底色     选中文字色  选中底色 */
```

### 0.4.5 ★ 改按钮的外观：位置 / 大小 / 文字 / 颜色 / 字体

一个按钮的全部外观，就这几样：

```c
ui_button(&b, x, y, w, h, label, on);
           └─┬─┘  └┬┘  └┬┘
           位置   大小  文字
                  ↑
       颜色由 ui_btn_colors(&b, fg, bg, fg_on, bg_on) 决定
```

#### ① 位置 —— 改 `x, y`

```c
ui_button(&b, 20,  40, 110, 36, "A", 0);     /* 左上角 (20, 40) */
ui_button(&b, 200, 40, 110, 36, "B", 0);     /* 往右挪到 200 */
```

`x, y` 是**左上角**坐标，屏幕是 480×272：
- x：`0 ~ 480-w`
- y：`0 ~ 272-h`

**排一行**：`x = 起始 + i * (宽 + 间距)`

```c
for (i = 0; i < 3; i++)
    ui_button(&s_btn[i], 20 + i * 120, 40, 110, 36, s_lab[i], 0);
    /*                     ↑ 20 / 140 / 260 */
```

**排两行**：

```c
x = 20 + (i % 2) * 120;      /* 0,1 列 */
y = 40 + (i / 2) * 50;       /* 每行往下 50 */
```

> 位置可以**每帧变**（比如做动画、跟随手指），`ui_button()` 每帧都会重新同步几何。
> 但变了位置要让它重画，见下面 ⑤。

#### ② 大小 —— 改 `w, h`

```c
ui_button(&b, 20, 40, 110, 36, "SMALL", 0);   /* 小：110 × 36 */
ui_button(&b, 20, 40, 200, 60, "BIG",   0);   /* 大：200 × 60 */
```

建议：

| 用途 | 建议尺寸 |
|---|---|
| 一般按钮 | `100 ~ 120` × `32 ~ 40` |
| 手指容易点中的最小尺寸 | **不小于 60 × 30** |
| 一排铺满 480 宽，N 个按钮 | `w = 480/N - 间距` |

> 高度最小别低于 **24**（Font12 字高 12，加上下留白）。太扁文字会被边框压住。
> 触摸命中判定用的是**整个矩形**，所以按钮可以比字大很多，更好点。

#### ③ 文字 —— 改 `label`

```c
ui_button(&b, 20, 40, 110, 36, "START", 0);    /* 显示 START */
ui_button(&b, 20, 40, 110, 36, "PAGE 1", 0);   /* 带空格也行 */
ui_button(&b, 20, 40, 110, 36, 0, 0);          /* 不写字，自己画图标 */
```

- **只能 ASCII**（字体只有 0x20~0x7E），**中文会显示成空白**
- 字是**自动居中**的（水平 `b->x + b->w/2`，垂直 `b->y + (b->h - 12)/2`），你不管对齐
- 文字太长会**溢出按钮边界**（不裁剪），所以要保证 `字符串宽度 < w`

**算一下够不够宽**：

```c
int tw = ui_text_w("START");          /* 每个字符 8px（7 字宽 + 1 间距）*/
/* "START" = 5 字符 = 40px，按钮 w=110 完全够 */
```

> 大约**每个字符占 8 像素**，所以 `w` 至少要 `字符数 × 8 + 16`（左右各留 8 像素边）。

#### ④ 颜色 —— `ui_btn_colors()`

```c
void ui_btn_colors(ui_btn_t *b, uint16_t fg, uint16_t bg,
                   uint16_t fg_on, uint16_t bg_on);
```

| 参数 | 含义 | 什么时候看到 |
|---|---|---|
| `fg` | 文字色 | 松手、未选中 |
| `bg` | 底色 | 同上 |
| `fg_on` | 高亮文字色 | **按下时** 或 `on=1` 时 |
| `bg_on` | 高亮底色 | 同上 |

```c
/* 深蓝底白字 → 按下变亮蓝底绿字（和默认一样）*/
ui_btn_colors(&b, C_TB_TX, C_TB_BTN, C_GREEN, C_TB_BTN_ON);

/* 黄底黑字 → 按下变白底黑字 */
ui_btn_colors(&b, C_BLACK, C_AMBER, C_BLACK, C_WHITE);

/* 红框警示按钮 */
ui_btn_colors(&b, C_WHITE, C_RED, C_RED, C_WHITE);
```

常用颜色（在 `ui_layout.h`，或自己 `ui_rgb(r,g,b)` 造）：

| 常量 | 颜色 | 常量 | 颜色 |
|---|---|---|---|
| `C_WHITE` | 白 | `C_BLACK` | 黑 |
| `C_RED` | 红 | `C_GREEN` | 绿 |
| `C_BLUE` | 亮蓝 | `C_AMBER` | 橙黄 |
| `C_CH1` | 黄 | `C_CH2` | 青 |
| `C_BG` | 屏幕底（黑）| `C_EDGE` | 灰边框 |
| `C_TB_BTN` | 深蓝 | `C_TB_BTN_ON` | 亮蓝 |
| `C_DIM` | 暗灰字 | `C_MEAS` | 浅灰 |

> `ui_btn_colors()` 可以在**任何时候**调（第一次之前或运行中），
> 它会自动置 `drawn = 0`，下一帧就按新配色重画，不用再调 `ui_btn_invalidate()`。
>
> **按下时的高亮是 `ui_button()` 内置行为**，由 `bg_on` / `fg_on` 决定，
> 你只要设好这两个颜色，按下自动变色，不用写任何额外代码。

#### ⑤ 改了位置/大小之后要重画

`ui_button()` 内部只比较"视觉状态对不对"，**位置和大小不在比较范围内**：

```c
/* 如果按钮挪了位置，旧位置那块的图形会留下来 */
b->x = 新位置;   这样不行，要走 ui_button() 传新坐标
```

正确做法 —— 挪位置时手动让旧区域清掉：

```c
ui_clear(C_BG);              /* 或者 ui_fill 盖掉旧位置那块 */
ui_btn_invalidate(&b);       /* 让按钮在新位置重画 */
```

如果位置是每帧算的动态布局（比如列表滚动），每帧都调一次 `ui_btn_invalidate(&b)` 即可，不会闪。

#### ⑥ 改字体大小（★ 目前要改源码）

`btn_paint()` 里字体是**写死 `Font12`** 的，`ui_button()` 没有字体参数：

```c
/* ui_render.c:1015 —— 目前写死 Font12 */
txt_c(&Font12, b->x + b->w / 2, b->y + (b->h - F12H) / 2, b->label, fg, (int32_t)bg);
```

**三种办法**：

**办法 1（最简单）：不用 label，自己画大字**
`label` 传 `0`，然后在 `ui_button()` 后面自己用 `ui_text16()` 画：

```c
if (ui_button(&b, 20, 40, 160, 40, 0, 0)) { /* 点中了 */ }
ui_text_c16(100, 52, "START", C_WHITE, UI_BG_NONE);    /* 居中画 16 号字 */
/*         ↑ 按钮中心 x = 20 + 160/2 = 100 */
```

> 这样最省事，不用改库。缺点是按钮重画时你自己画的字不会跟着重画，
> 所以只在按钮位置固定时好用。

**办法 2：改 `btn_paint()` 用 Font16**

```c
/* ui_render.c 第 1015 行，把 Font12 换成 Font16，F12H 换成 F16H */
txt_c(&Font16, b->x + b->w / 2, b->y + (b->h - F16H) / 2, b->label, fg, (int32_t)bg);
```

改完全部按钮都变大字，而且仍然自动居中。注意 `h` 要相应加高（建议 ≥ 20）。

**办法 3：给 `ui_btn_t` 加字体成员**（要动头文件，最灵活）

`Font12` / `Font16` 的类型是 `sFONT`（定义在 `fonts.h`）。`ui_render.h` 里没 include 它，
所以在头文件里用 `const void *` 过渡，在 `ui_render.c` 里再强转回去：

```c
/* ---- ui_render.h：ui_btn_t 末尾加一个成员 ---- */
typedef struct
{
    ...
    uint8_t  last_vis;
    const void *font;        /* 新增：0 = 用默认 Font12 */
} ui_btn_t;

/* ---- ui_render.h：UI_BTN_DEFAULT 末尾也要补一个 0 ---- */
```

```c
/* ---- ui_render.c：btn_paint() ---- */
static void btn_paint(const ui_btn_t *b, int vis)
{
    uint16_t bg = vis ? b->bg_on : b->bg;
    uint16_t fg = vis ? b->fg_on : b->fg;

    fillrect(b->x, b->y, b->w, b->h, bg);
    rect_(b->x, b->y, b->w, b->h, vis ? b->fg_on : C_EDGE);

    if (b->label != 0)
    {
        const sFONT *f    = b->font ? (const sFONT *)b->font : &Font12;
        int          fh   = (f == &Font16) ? F16H : F12H;

        txt_c(f, b->x + b->w / 2, b->y + (b->h - fh) / 2,
              b->label, fg, (int32_t)bg);
    }
}

/* ---- ui_render.c：暴露一个设字体的函数 ---- */
void ui_btn_font(ui_btn_t *b, const void *font)
{
    if (b == 0) return;
    b->font  = font;
    b->drawn = 0;              /* 下一帧重画 */
}
```

```c
/* ---- 用法：ui_demo.c ---- */
/* 需要让 ui_render.h 能见到 Font16，所以在 ui_demo.c 里 include fonts.h */
#include "fonts.h"

static ui_btn_t b_big = UI_BTN_DEFAULT;

static void ui_init_btns(void)
{
    ui_btn_font(&b_big, &Font16);        /* 这个按钮用 16 号字 */
}
```

> 这个办法要改 `ui_render.h` 的结构体和宏，容易漏改 `UI_BTN_DEFAULT` 的初始化项，
> **考试时别用**，用办法 1。

一般考试用**办法 1 就够了**，不用改库。

### 0.6 完整最小骨架

```c
static Touch_State ts;
static ui_btn_t    b = UI_BTN_DEFAULT;
static int         on;

static void my_ui(void)
{
    if (ui_button(&b, 20, 40, 100, 36, "ON/OFF", on))
    {
        on = !on;
        ui_btn_invalidate(&b);
    }
}

int main(void)
{
    /* ... CubeMX 初始化（记得有 MX_I2C3_Init）... */
    ui_init();
    Touch_Init();
    ui_set_custom(my_ui);

    while (1)
    {
        Touch_Poll(&ts);
        ui_touch_set(ts.pressed ? (int)ts.x : -1,
                     ts.pressed ? (int)ts.y : -1,
                     (int)ts.pressed);
        ui_draw(&w);
        HAL_Delay(20);
    }
}
```

**四步就这些**：`ui_btn_t b = UI_BTN_DEFAULT;` → 每帧 `ui_button(...)` → 返回 1 就干活 → `ui_touch_set()` 别忘。

### 0.7 ★ 触摸按键 vs 物理按键：分别写在哪

新手最常问的问题。板子上有**两种按键**，写法完全不同：

| | 触摸按键（屏幕上的） | 物理按键（板子上的 PG7） |
|---|---|---|
| **在哪定义** | `ui_main()` / `my_ui()` 里面 | 不用定义，`key.c` 已经做好了 |
| **怎么读** | `ui_button()` 返回 1 | `get_keynum()` 返回 1/2/3 |
| **写在哪个文件** | **`ui_demo.c`** | **`main.c` 的主循环** |
| **谁负责画** | `ui_button()` **自己画** | 你自己在 `ui_main()` 里按状态画 |
| **长按/双击** | 不支持（只有"按下"一下就触发） | 支持：`1`=长按 `2`=双击 `3`=单击 |

**关键结论：`ui_main()` 里绝对不要调 `get_keynum()`。**

因为 `get_keynum()` 是**消费型**的 —— 读一次就把 `keynum` 清零：

```c
uint8_t get_keynum(void)
{
    uint8_t temp = keynum;
    keynum = 0;            /* ★ 取完就清零，别的文件就读不到了 */
    return temp;
}
```

`ui_main()` 每秒只被调 25 次，主循环跑得更快；而且 `ui_main()` 的职责是"画"，读按键放进去会打乱分工。

**正确分工：**

```c
/* ========== main.c 主循环：读物理按键 ========== */
while (1)
{
    key_mod = get_keynum();            /* 1=长按 2=双击 3=单击，取完自动清零 */
    if (key_mod != 0)
    {
        if (key_mod == 3)  g_page = (g_page + 1) % 3;   /* 单击 = 切页 */
        if (key_mod == 1)  g_run  = !g_run;             /* 长按 = 暂停/运行 */
        key_mod = 0;
    }
    ...
}
```

```c
/* ========== ui_demo.c 的 ui_main()：只按状态画，不读按键 ========== */
static void ui_main(void)
{
    if (g_page == 0)      { /* 画第 0 页 */ }
    else if (g_page == 1) { /* 画第 1 页 */ }
    else                  { /* 画第 2 页 */ }
}
```

中间的 `g_page` / `g_run` 就是跨文件传参（定义在 `app_data.h`，见 `ADC到屏幕使用说明.md` 第 5 章）。

> **一句话**：物理按键在 `main.c` 里读、触摸按键在 `ui_main()` 里创建，两者都通过全局变量影响界面。

### 0.8 点一下切换一次页面（多按钮 + 高亮）

这是最常用的模式：几个按钮代表几页，当前页的按钮高亮。

```c
#define NB 3

static ui_btn_t    s_btn[NB] = { UI_BTN_DEFAULT, UI_BTN_DEFAULT, UI_BTN_DEFAULT };
static const char *s_lab[NB] = { "PAGE1", "PAGE2", "PAGE3" };
static int         s_page;                     /* 当前第几页 */

static void ui_main(void)
{
    int i;

    /* 按钮排成一行 */
    for (i = 0; i < NB; i++)
    {
        /* ★ 最后的 on 参数传 s_page == i：哪个是当前页，哪个就高亮 */
        if (ui_button(&s_btn[i], 20 + i * 120, 40, 110, 36, s_lab[i], s_page == i))
        {
            s_page = i;
        }
    }

    /* 下面根据 s_page 画页面内容 */
    switch (s_page)
    {
        case 0: ui_text16(20, 100, "PAGE ONE",   C_WHITE, UI_BG_NONE); break;
        case 1: ui_text16(20, 100, "PAGE TWO",   C_CH1,   UI_BG_NONE); break;
        case 2: ui_text16(20, 100, "PAGE THREE", C_CH2,   UI_BG_NONE); break;
    }
}
```

要点：

- `on` 参数传 **`s_page == i`**，切换页面时高亮自动跟着走，**不用手动 `ui_btn_invalidate()`**
- 数组必须整串用 `UI_BTN_DEFAULT` 初始化（或循环 `ui_btn_init()`）

**只有一个按钮、点一下翻页**（不关心高亮）：

```c
static ui_btn_t b_next = UI_BTN_DEFAULT;

if (ui_button(&b_next, 20, 40, 110, 36, "NEXT", 0))
    s_page = (s_page + 1) % 3;
```

> 想切页时**整屏重画**（比如页面内容完全不同），在 `s_page` 变化后调一次
> `ui_force_redraw()` 或 `ui_clear(C_BG)` + `ui_btn_invalidate(&s_btn[i])`，
> 否则旧页面的字会残留。

### 0.9 常见错误速查

| 现象 | 原因 | 解决 |
|---|---|---|
| **按钮看不见 / 全黑一片** | 用了 `= {0}` 初始化 | 改成 `= UI_BTN_DEFAULT` |
| **按钮闪** | 按钮对象不是 `static` | 加 `static`（见 0.3 ②） |
| **点了完全没反应** | 没调 `ui_touch_set()` | 主循环每轮调一次（见 0.5） |
| **点一下触发好几次 / 数加了好几** | 在 `ui_main()` 里又调了一遍 `ui_button()` | 一个按钮每帧只调一次 |
| **按住不放一直触发** | —— | 不会。`ui_button()` 自带防连发，按住只触发一次 |
| **手指划过几个按钮，全都响应** | —— | 不会。同一次触摸只有一个按钮触发 |
| **按钮被别的东西盖住后不刷新** | 缓冲以为"画过了" | `ui_btn_invalidate(&b)` |
| **切页后旧内容残留** | 整屏没人擦 | `ui_clear(C_BG)` 或 `ui_force_redraw()` |
| **触摸坐标是反的（x/y 互换）** | 屏方向 | `touch.c` 里 `Touch_Poll()` 内部已处理，一般不用管 |

## 1. 硬件与前提

| 项目 | 值 |
|---|---|
| 芯片 | **FT5336** 电容触摸控制器（和 LCD 一体的，不用接线）|
| 总线 | **I2C3**，**PH7 = SCL / PH8 = SDA**，复用 AF4 |
| 器件地址 | 7 位 `0x38` → 给 HAL 传 **`0x70`**（左移一位）|
| 中断脚 | PI13（本驱动用**轮询**，不用它）|
| 分辨率 | 480 × 272 |
| 面板方向 | 出厂按**竖屏**装，所以读出来的 **X/Y 要对调** |

### CubeMX 需要满足的前置条件

1. **I2C3 已启用**，引脚 PH7/PH8（工程里 `MX_I2C3_Init()` 已配好）
2. 不需要额外配 EXTI（轮询方式）
3. **不需要** 校准 —— 电容屏直接给数字坐标，没有 AD 值可标定

> 如果你的工程里没有 I2C3：CubeMX → Connectivity → I2C3 → I2C → Speed Mode 选
> Standard(100k) 或 Fast(400k)，引脚会自动落到 PH7/PH8。

## 2. 初始化（只要 3 步）

```c
#include "touch.h"
#include "ui_render.h"
#include "ui_demo.h"

static Touch_State s_ts;
static uint8_t     s_touch_ok;

int main(void)
{
    /* ... HAL_Init / SystemClock_Config ... */
    MX_GPIO_Init();
    MX_I2C3_Init();                 /* ← 触摸总线必须先初始化 */
    MX_LTDC_Init();

    /* ① 点亮屏幕 */
    ui_init();

    /* ② 初始化触摸屏 */
    s_touch_ok = (Touch_Init() == TOUCH_OK) ? 1u : 0u;
    printf("touch: %s, chip id 0x%02X\r\n",
           s_touch_ok ? "OK" : "NOT FOUND", Touch_ChipId());

    /* ③ 主循环 */
    while (1)
    {
        if (s_touch_ok)
        {
            (void)Touch_Poll(&s_ts);          /* 读一次 */

            ui_touch_set(s_ts.pressed ? (int)s_ts.x : -1,
                         s_ts.pressed ? (int)s_ts.y : -1,
                         (int)s_ts.pressed);  /* 交给界面（按钮响应要用，别省）*/
        }

        ui_draw(&w);                          /* 刷屏 */
        HAL_Delay(20);
    }
}
```

`Touch_Init()` 内部做了三件事：

```c
1. HAL_I2C_IsDeviceReady(&hi2c3, 0x70, 3, 100)   → 器件在不在
2. 读 0xA8 寄存器拿芯片 ID                        → 只用于调试打印
3. 往 0xA4(GMODE) 写 0                           → 切到轮询模式
```

> ⚠️ **第 3 步不能省**。有些批次的 FT5336 上电默认是"触发模式"，
> 不切轮询的话 `TD_STATUS` 永远是 0，按屏幕一点反应都没有。

## 3. 数据结构和函数

### `Touch_State`

```c
typedef struct
{
    uint8_t  pressed;   /* 1 = 手指在屏上，0 = 松开 */
    uint16_t x;         /* 0 ~ 479，已经交换成横屏方向 */
    uint16_t y;         /* 0 ~ 271 */
    uint8_t  count;     /* 触摸点数 0~5（单指就是 1）*/
} Touch_State;
```

`pressed == 0` 时 `x/y` 保留上一次的值（不清零），**所以判断有没有触摸只能看 `pressed`**。

### 函数一览

| 函数 | 作用 | 返回值 |
|---|---|---|
| `Touch_Init()` | 探测 + 读 ID + 切轮询模式 | `TOUCH_OK` / `TOUCH_ERR` |
| `Touch_ChipId()` | 读芯片 ID（调试用）| ID 字节，读到 0 说明 I2C 没通 |
| `Touch_Scan(&ts)` | 读一次原始状态，**不做边沿检测** | `TOUCH_OK` / `TOUCH_ERR` |
| **`Touch_Poll(&ts)`** | **读一次 + 边沿检测**（最常用）| `TOUCH_EV_*` 位组合，0 = 没变化 |
| `Touch_Last()` | 读回最近一次 Poll 的结果（只读指针）| `const Touch_State *` |

### `Touch_Poll()` 的事件位

```c
#define TOUCH_EV_DOWN   0x01    /* 刚按下（一次触摸只触发一次）*/
#define TOUCH_EV_UP     0x02    /* 刚抬起 */
#define TOUCH_EV_MOVE   0x04    /* 按住并且位置变了 */
```

```c
uint8_t ev = Touch_Poll(&s_ts);

if (ev & TOUCH_EV_DOWN) { /* 刚开始按 */ }
if (ev & TOUCH_EV_MOVE) { /* 手指在滑动 */ }
if (ev & TOUCH_EV_UP)   { /* 松手了 */ }
if (ev == 0)            { /* 没变化，位置可以继续用 s_ts.x/y */ }
```

> 内部已经处理了 **I2C 偶发错误**：连续 3 次读失败才认定"松开"，
> 免得一次通信抖动把一次点击算成两次。

## 5. 触摸的"显示"部分

### 5.1 十字准星（默认**不画**，想要才开）

**先说结论：不调任何东西，屏幕上就不会有十字。** 想显示就加一句开关：

```c
/* 想要十字准星 */
ui_cursor_enable(1);

/* 不想要（默认就是这个状态，可以显式写出来）*/
ui_cursor_enable(0);
```

开关是**独立**的，`ui_touch_set()` 照常调用（它负责把坐标交给界面、让按钮能响应）：

```c
ui_touch_set(s_ts.pressed ? (int)s_ts.x : -1,
             s_ts.pressed ? (int)s_ts.y : -1,
             (int)s_ts.pressed);
```

开了之后 `ui_draw()` 会在**波形区（y 20~226）**画一个 15×15 的红色十字：
- 按住时是红色，抬起自动擦掉
- 擦除走 `bg_at()`，所以**不会在网格上留痕迹**
- 只在波形区画；状态栏/工具条上靠按钮变色做反馈

**完整说明**：

```c
void ui_cursor_enable(int on);      /* 0 = 不画（默认），1 = 画 */
int  ui_cursor_is_on(void);         /* 查当前状态：1=开 0=关 */
```

| 要点 | 说明 |
|---|---|
| **不影响触摸功能** | 关掉准星，`ui_button()` 照样正常响应 |
| **只影响画不画** | `ui_touch_set()` 该调还得调（它记录坐标给按钮用）|
| **随时可切** | 开机调一次，或运行中当设置项切换 |
| **关掉会擦干净** | `ui_cursor_enable(0)` 会把已画在屏幕上的十字擦掉 |

> 为什么默认关：大部分界面不需要十字，而且它会盖住你在波形区画的内容。
> 调试触摸坐标时可以临时打开。

### 5.2 把坐标写到屏幕上

用 `ui_field()` 最省事 —— **内容没变就一个像素都不碰**：

## 6. ★ 数字怎么转成字符串显示

### 6.1 为什么不用 `sprintf`

```c
sprintf(buf, "%.2f V", v);      /* ✗ 不要这样 */
```

- MicroLIB 下的**浮点格式化会链进几十 KB 的库**，Flash 一下子涨一大截
- 速度慢，在 25 fps 的刷屏循环里很浪费
- 还可能和 `printf` 重定向（SWO）打架

自己用**定点整数**格式化，几百字节就够，而且快得多。

### 6.2 三个函数

```c
char *ui_str (char *p, const char *s);        /* 拷贝字符串 */
char *ui_itoa(char *p, int32_t v);            /* 整数 */
char *ui_fix (char *p, int32_t v, int dec);   /* 定点小数 */
```

**三个都返回"新的字符串末尾指针"**，所以能链着写：

```c
char buf[24], *p = buf;

p = ui_str(p, "CH1 = ");
p = ui_fix(p, 165, 2);        /* 1.65 */
p = ui_str(p, " V");
/* buf 里现在就是 "CH1 = 1.65 V" */

ui_text(10, 10, buf, C_WHITE, UI_BG_NONE);
```

### 6.3 `ui_itoa()` —— 整数

```c
char buf[12];
ui_itoa(buf, 1234);       /* -> "1234"  */
ui_itoa(buf, -56);        /* -> "-56"   */
ui_itoa(buf, 0);          /* -> "0"     */
```

### 6.4 `ui_fix()` —— 定点小数（★ 关键：参数是"值 × 10^dec"）

```c
ui_fix(p, 165,  2);       /* -> "1.65"   */
ui_fix(p, 3300, 2);       /* -> "33.00"  */
ui_fix(p, 5,    1);       /* -> "0.5"    */
ui_fix(p, -5,   1);       /* -> "-0.5"   */
ui_fix(p, 42,   0);       /* -> "42"     （dec=0 就是纯整数）*/
ui_fix(p, 1650, 3);       /* -> "1.650"  */
```

**记法：`dec` 是小数位数，传进去的数是"真实值 × 10^dec"。**
`1.65` 要传 `165` 配 `dec=2`，或者传 `1650` 配 `dec=3`。

### 6.5 常见换算场景

#### ① ADC 12 位码值 → 电压

```c
uint16_t code = 2048;                          /* 0 .. 4095 */
int32_t  mv   = (int32_t)code * 3300 / 4095;   /* 毫伏，0..3300 */

char buf[16], *p = buf;
p = ui_fix(p, mv, 3);                          /* -> "1.650" */
p = ui_str(p, " V");
ui_text(10, 10, buf, C_AMBER, UI_BG_NONE);
```

> 为什么先算毫伏再 `dec=3`？因为整数运算没有精度损失，
> 而 `code * 3.3 / 4095` 用浮点会引入误差，还得链浮点库。

#### ② 频率自动换挡（Hz / kHz / MHz）

```c
static char *fmt_freq(char *p, uint32_t hz)
{
    if (hz >= 1000000u)      { p = ui_fix(p, (int32_t)(hz / 10000u), 2); p = ui_str(p, " MHz"); }
    else if (hz >= 1000u)    { p = ui_fix(p, (int32_t)(hz / 100u),   2); p = ui_str(p, " kHz"); }
    else                     { p = ui_itoa(p, (int32_t)hz);              p = ui_str(p, " Hz");  }
    return p;
}
/* 1250000 -> "1.25 MHz"   12500 -> "125.00 kHz"   500 -> "500 Hz" */
```

#### ③ 时间从 ns 自动换挡

```c
static char *fmt_time(char *p, uint32_t ns)
{
    if (ns >= 1000000u)   { p = ui_fix(p, (int32_t)(ns / 10000u), 2); p = ui_str(p, " ms"); }
    else if (ns >= 1000u) { p = ui_fix(p, (int32_t)(ns / 10u),    2); p = ui_str(p, " us"); }
    else                  { p = ui_itoa(p, (int32_t)ns);              p = ui_str(p, " ns"); }
    return p;
}
```

#### ④ 百分比

```c
int32_t pct = (int32_t)done * 100 / total;      /* 0..100 */
p = ui_itoa(p, pct);
p = ui_str(p, " %");
```

#### ⑤ 拼一行多项数据

```c
char buf[40], *p = buf;

p = ui_str(p, "CH1 ");
p = fmt_freq(p, 1250);
p = ui_str(p, "  Vpp=");
p = ui_fix(p, 320, 2);           /* 3.20 */
p = ui_str(p, "V");
ui_text(10, 30, buf, C_CH1, UI_BG_NONE);
```

### 6.6 对齐技巧

`ui_field()` 会把文字**居中**画进给定的矩形，所以固定宽度的数字框不会左右乱跳：

```c
ui_field(0, 100, 40, 80, 18, buf, C_WHITE, C_BG);   /* 宽度锁死 80px */
```

如果要**右对齐**（数字位数变化时右边缘不动），自己算起点：

```c
int w = ui_text_w(buf);
ui_text(x + 80 - w, y, buf, C_WHITE, UI_BG_NONE);
```

### 6.7 坑

| 坑 | 说明 |
|---|---|
| **缓冲区太小** | `ui_itoa` 最坏要 11 字符（`-2147483648`），`buf` 至少 12；带单位和多项的话给 24~40 |
| **忘了用返回值** | 链式写的时候必须 `p = ui_str(p, ...)`，不能只写 `ui_str(p, ...)`，否则下一段会覆盖前面 |
| **`ui_fix` 的参数是"值×10^dec"** | 传 `1.65` 是错的（那是个浮点数），要传 `165` + `dec=2` |
| **`ui_itoa` 传 `INT32_MIN`** | `-v` 会溢出（未定义），实际不会用到；真要用就自己拆 |
| **浮点本身** | 整个工程尽量别用 `float` 做显示。要用就 `ui_fix((int32_t)(v * 100), 2)` 先转定点 |
| **中文** | 字库只有 ASCII `0x20~0x7E`，字符串里写中文会显示成空白 |

## 7. 完整可跑例子：触摸坐标显示器

```c
#include "main.h"
#include "touch.h"
#include "ui_render.h"
#include "ui_layout.h"

static Touch_State s_ts;
static ui_btn_t    s_btn = UI_BTN_DEFAULT;
static int         s_clicks;

/* 每帧绘制 */
static void my_ui(void)
{
    const Touch_State *t = Touch_Last();
    char buf[28], *p;

    /* --- 标题 --- */
    ui_text16(10, 8, "TOUCH TEST", C_WHITE, UI_BG_NONE);
    ui_hline(10, 470, 28, C_EDGE);

    /* --- 坐标（用 ui_field 差量刷新，不变就不重画）--- */
    p = ui_str(buf, "pressed = ");
    p = ui_itoa(p, (int32_t)t->pressed);
    ui_field(0, 10, 40, 140, 18, buf, t->pressed ? C_GREEN : C_DIM, C_BG);

    p = ui_str(buf, "x = ");
    p = ui_itoa(p, (int32_t)t->x);
    ui_field(1, 10, 64, 110, 18, buf, C_CH1, C_BG);

    p = ui_str(buf, "y = ");
    p = ui_itoa(p, (int32_t)t->y);
    ui_field(2, 130, 64, 110, 18, buf, C_CH2, C_BG);

    p = ui_str(buf, "points = ");
    p = ui_itoa(p, (int32_t)t->count);
    ui_field(3, 250, 64, 130, 18, buf, C_WHITE, C_BG);

    /* --- 换算演示：把 x 当成 0..479 的比例，显示成 0~100% --- */
    p = ui_str(buf, "x% = ");
    p = ui_fix(p, (int32_t)t->x * 1000 / 479, 1);     /* 值x10 -> "50.3" */
    p = ui_str(p, "%");
    ui_field(4, 10, 90, 140, 18, buf, C_AMBER, C_BG);

    /* --- 一个可点按钮 --- */
    if (ui_button(&s_btn, 10, 130, 120, 34, "TAP ME", 0))
    {
        s_clicks++;
        ui_btn_invalidate(&s_btn);
    }

    p = ui_str(buf, "clicks = ");
    p = ui_itoa(p, s_clicks);
    ui_field(5, 150, 138, 140, 18, buf, C_GREEN, C_BG);

    /* --- 提示 --- */
    ui_text(10, 200, "hold the panel, watch the crosshair below",
            C_GRID_MAJ, UI_BG_NONE);
}

int main(void)
{
    uint8_t ok;

    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_I2C3_Init();                 /* 触摸总线 */
    MX_LTDC_Init();

    ui_init();
    ui_chrome_enable(0);            /* 整屏自己画 */

    ok = (Touch_Init() == TOUCH_OK) ? 1u : 0u;
    if (!ok)
        ui_text(10, 240, "FT5336 NOT FOUND - check I2C3", C_RED, UI_BG_NONE);

    ui_set_custom(my_ui);

    {
        static wave_window_t w;
        static uint32_t frame = 0;

        while (1)
        {
            (void)Touch_Poll(&s_ts);
            ui_touch_set(s_ts.pressed ? (int)s_ts.x : -1,
                         s_ts.pressed ? (int)s_ts.y : -1,
                         (int)s_ts.pressed);

            frame++;
            ui_draw(&w);            /* w 里没有波形数据时可先关掉通道 */
            HAL_Delay(20);
        }
    }
}
```

> 上面 `ui_draw(&w)` 用的是空的 `w`；如果只想画自己的界面，
> 可以把 `g_ui.ch_mask = 0`，`ui_draw()` 就只负责调你的回调。

## 8. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `Touch_Init()` 返回 `TOUCH_ERR` | ① `MX_I2C3_Init()` 没调 ② PH7/PH8 被别的外设占了 ③ 上拉电阻/硬件问题 |
| `ChipId()` 读到 0 | I2C 通了但读失败，先确认 `HAL_I2C_Mem_Read` 返回 `HAL_OK` |
| 按下没反应，坐标一直 0 | 芯片在**触发模式**，`Touch_Init()` 里那句写 `GMODE(0xA4)=0` 不能省 |
| 坐标完全错乱 | `& 0x0F` 漏了，或者轴没交换（`x = raw_y; y = raw_x;`）|
| x 一直小于 272 | 轴没交换 |
| 坐标范围大得离谱（16000 多）| 拼 12 位坐标时没 `& 0x0F`，把事件标志当成了高位 |
| 点一次触发两次 | 旧版本问题；现在 `Touch_Poll()` 已做 I2C 失败容忍，不会误判 |
| **准星不出现** | **默认就是关的**，要显示得调 `ui_cursor_enable(1)`；另外触摸点必须在 y 20~226（只在波形区画） |
| 开了准星还是不出现 | ① `ui_touch_set()` 没调 ② 触摸点在状态栏/工具条上（只在波形区画）|
| 准星卡住不消失 | 松手时要把 `x/y` 传 `-1`：`ui_touch_set(pressed ? x : -1, ...)` |
| **想去掉准星** | 默认就没有；如果之前开了，调 `ui_cursor_enable(0)` |
| 加了开关但准星还在 | `ui_cursor_enable()` 要在 `ui_init()` 之后调 |
| 数字显示成方块/空白 | 用了中文或非 ASCII 字符，字库只有 `0x20~0x7E` |
| 数字显示乱码 | `ui_fix()` 的 `dec` 和传进去的值不匹配（值是"真实值×10^dec"）|
| 数字最后一位变来变去 | 正常，浮点/整数除法末位抖动；想稳定就少一位小数或加死区 |

## 附：最小速查

```c
/* 初始化 */
uint8_t     Touch_Init(void);                 /* TOUCH_OK / TOUCH_ERR */
uint8_t     Touch_ChipId(void);               /* 调试用 */

/* 读 */
uint8_t     Touch_Scan(Touch_State *ts);      /* 不做边沿检测 */
uint8_t     Touch_Poll(Touch_State *ts);      /* ★ 常用，返回 TOUCH_EV_* */
const Touch_State *Touch_Last(void);          /* 只读最近一次结果 */

/* 显示 */
void  ui_touch_set(x, y, pressed);            /* 把触摸位置交给界面、让按钮能响应 */
void  ui_cursor_enable(on);                   /* 十字准星：0=不画(默认) 1=画 */
int   ui_cursor_is_on(void);                  /* 查准星状态 */
void  ui_chrome_enable(int on);               /* 0 = 整屏自己画 */

/* 数字 -> 字符串 */
char *ui_str (char *p, const char *s);
char *ui_itoa(char *p, int32_t v);
char *ui_fix (char *p, int32_t v, int dec);   /* v = 值 × 10^dec */
```
