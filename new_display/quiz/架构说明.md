# 工程架构说明（三层）

> 本工程按 **硬件驱动层 / 软件功能层 / 主函数层** 三层组织，参考 `DS2026` 的分层方式。
>
> 分层原则：**上层可以调用下层，下层绝不调用上层**。

---

## 二、三层职责

| 层 | 目录 | 职责 | 允许依赖 |
|---|---|---|---|
| **主函数层** | `Core/` | 系统时钟、MPU、外设初始化；主循环节拍；把各层串起来 | 可调 Drv 和 App |
| **软件功能层** | `App/` | 绘图、波形、测量、界面布局、菜单交互、定时器事件分发 | 可调 Drv |
| **硬件驱动层** | `Drv/` | 只操作具体外设（LTDC/SDRAM/I2C/GPIO/字体数据），不关心业务 | 只调 HAL |

依赖方向：`Core` → `App` → `Drv` → `HAL`，**单向，无环**。

## 四、main.c 现在长什么样

主函数层只保留 CubeMX 生成的代码，我们自己的全部收进 `app_init()` / `app_task()`。
`main()` 里一共只有三行用户代码：

```c
int main(void)
{
  /* USER CODE BEGIN 1 */
  drv_mpu_config();          /* Drv：MPU 必须先于 HAL_Init */
  /* USER CODE END 1 */

  HAL_Init();
  SystemClock_Config();

  MX_GPIO_Init();  MX_TIM3_Init();  MX_TIM1_Init();
  MX_ADC3_Init();  MX_USART1_UART_Init();
  MX_I2C3_Init();  MX_LTDC_Init();

  /* USER CODE BEGIN 2 */
  app_init();                /* App：各层初始化编排 */
  /* USER CODE END 2 */

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */
    /* USER CODE BEGIN 3 */
    app_task();              /* App：主循环一次任务 */
  }
  /* USER CODE END 3 */
}
```

`app_init()` 内部按顺序做：DWT 计时器 → 定时器中断 → 调试输出 → SDRAM 自检 →
显示初始化 → 注册界面 → 触摸初始化。

`app_task()` 内部按顺序做：读按键 → 读触摸并分发给界面 → 造一窗波形 → 画一帧。

> 好处：CubeMX 重新生成代码时，我们的逻辑一行都不会丢，
> 而且 `main.c` 永远是干净的生成代码。
## 五、为什么要这么分

| 好处 | 说明 |
|---|---|
| **换屏幕只改 Drv** | 换面板/换驱动芯片，只动 `drv_lcd.c`，App 一行不改 |
| **换界面只改 App** | 改布局、加页面，只动 `app_gfx.c` / `app_ui.c` |
| **可测试** | 可以先用仿真数据跑 App，不接采集端 |
| **分工明确** | 两人合作时，一人写 Drv（硬件），一人写 App（界面） |

## 六、注意事项

1. **下层不许 include 上层的头文件**
   - `Drv/*.c` 只 include `main.h`、自己的头、HAL/CubeMX 头
   - `App/*.c` 可以 include `Drv/*.h`
   - `Core/main.c` 什么都可以 include

2. **跨层调用只用头文件里声明过的函数**，不要 `extern` 别层的变量

3. **`app_gfx.c` 里的 `static` 函数是私有的**，只有 `app_gfx.h` 里声明的才是对外接口

4. **Keil 工程**里已经建好 `Drv` 和 `App` 两个分组，include 路径已加：
   ```
   ../Core/Inc;../Drv;../App;../Drivers/...
   ```

## 七、新增一个功能的正确做法

以"增加 CH3 模拟通道"为例：

1. **Drv**：无需改（ADC 已在 Core 里配好）
2. **App/app_layout.h**：加颜色常量 `C_CH3`
3. **App/app_gfx.h**：`wave_window_t` 加 `ch3[NPT]` 字段
4. **App/app_gfx.c**：`trace_ana` 加一路绘制、`ui_measure` 加一路测量
5. **App/app_ui.c**：`app_ui_fill` 里填 `ch3[]` 仿真数据
6. 完成 —— `main.c` 完全不用动

这就是分层的好处：**改动只落在该落的那一层**。
